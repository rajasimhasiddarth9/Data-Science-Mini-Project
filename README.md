# Data-Science-Mini-Project
This project explores student performance using a real-world dataset from the UCI Machine Learning Repository.
# Objectives

Explore and clean a dataset using Pandas.

Calculate descriptive statistics using NumPy and Pandas.

Visualize grade distributions and relationships between student-related factors.

Identify data-driven findings from exploratory data analysis.

# Tools and Technologies

Python

Pandas

NumPy

Matplotlib

Seaborn

Google Colab

# Dataset

UCI Student Performance Dataset: https://archive.ics.uci.edu/dataset/320/student-performance

# Project Workflow

Data loading and exploration

Data quality checks

Statistical analysis

Data visualization

Findings and conclusion
